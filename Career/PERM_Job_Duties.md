# PERM Job Duties – Data Engineer / Software Engineer

## Proposed Eight-Line Job Duties (Aligned with Prior H-1B Description)

1. Design, develop, document, and optimize large-scale data engineering solutions, collaborating with technical teams to establish reliable architecture and platform standards.
2. Develop and maintain automated data ingestion, transformation, validation, and storage pipelines using Python, PySpark, Apache Spark, SQL, and distributed computing frameworks.
3. Build reusable ETL, data quality, and reconciliation frameworks, including schema checks, deduplication, integrity controls, and source-to-target validations.
4. Design logical and physical data models, manage schema evolution and metadata, and optimize storage formats, partitioning, and indexing strategies for data platforms.
5. Automate and orchestrate enterprise data processing workflows using Apache Airflow, AutoSys, and other scheduling tools with monitoring and failure recovery.
6. Tune Spark and Hadoop/YARN workloads for performance and resource efficiency, using monitoring, logging, tracing, and root-cause analysis to maintain system reliability.
7. Develop and support scalable cloud-native data solutions using AWS, Databricks, Snowflake, and Apache Iceberg, including cloud data lake integration and migration.
8. Collaborate with architects, analysts, and platform teams to improve data processing solutions, and integrate data preparation or machine learning pipelines where these are actual assigned responsibilities.
