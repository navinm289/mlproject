# Job Duties – Data Engineer / Software Engineer

1. Design, develop, and maintain scalable data processing applications and ETL pipelines using Python, PySpark, Apache Spark, and SQL.
2. Develop and optimize data ingestion, transformation, and integration workflows across multiple enterprise data sources.
3. Build and maintain big data solutions using Hadoop, Hive, Databricks, AWS, and Apache Iceberg.
4. Design and implement reusable data engineering frameworks for data validation, quality checks, and reconciliation.
5. Develop and manage automated data workflows using Apache Airflow, AutoSys, and enterprise scheduling tools.
6. Optimize data processing performance through efficient query design, partitioning, and distributed computing techniques.
7. Support cloud migration, data lake development, and integration of enterprise applications with cloud-based platforms.
8. Troubleshoot production issues, enhance application reliability, and collaborate with cross-functional teams to deliver business solutions.
