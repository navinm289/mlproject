QUICK START EXAMPLE:
================================================================================

Configuration (conf.json):
{
  "uat": [
    { "file": "customer.sas", "basefile": true },
    { "file": "account.sas", "join": {"type": "inner", "keys": ["cust_id"]} },
    { "file": "daily_*.sas", "union": true, "join": {"type": "inner", "keys": ["date"]} }
  ]
}

Python Code:
from pyspark.sql import SparkSession
from mlproject.stack_processor import create_data_stack

spark = SparkSession.builder.appName("DataProcessing").getOrCreate()
df = create_data_stack(spark, "conf.json", env="uat")

Processing Flow:
1. Load customer.sas as base
2. JOIN account.sas on cust_id
3. Find all daily_*.sas files
4. UNION all daily files together
5. JOIN result on date
6. Return final DataFrame

INTEGRATION STEPS:
================================================================================

1. Copy stack_processor.py to your project:
   cp src/mlproject/stack_processor.py <your-project>/

2. Install PySpark (if not already installed):
   pip install pyspark>=3.0

3. Create conf.json with your file paths:
   {
     "uat": [
       { "file": "path/to/base.sas", "basefile": true },
       { "file": "path/to/file2.sas", "join": {"type": "inner", "keys": ["id"]} }
     ]
   }

   from mlproject.stack_processor import create_data_stack
   df = create_data_stack(spark, "conf.json")

   pytest tests/test_stack_processor.py -v
